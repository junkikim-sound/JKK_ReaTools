JKK_ReaTools top bar launcher icons
===================================
Put PNG files here (white #FFFFFF on a transparent background is recommended;
they are tinted with the JKK Theme text color). Square images, e.g. 64x64.
While a file is missing, the button shows its letter instead.
Files are re-checked every 2 seconds, so new icons appear without restarting.
